Privacy Policy

zionos is a personal, single-user application used only by its owner.

  • Google user data (Gmail, Calendar, Drive, Docs, Sheets, Contacts) is accessed only for the owner's own account, only to provide the owner with briefings, reminders and drafts.
  • Data is processed on the owner's private server and is not sold, shared with, or transferred to third parties, and is not used for advertising.
  • Access can be revoked at any time at myaccount.google.com/permissions.

zionos's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
